# UX/UI design

**Editable Figma file:** https://www.figma.com/design/x45moe42CMHbzgNk8wAyHU

## Designed screens

1. Home page — featured projects, call to action.
2. Job catalogue — listing cards and search/filter panel.
3. Job detail — description, client, budget and bid action.
4. Submit bid — form for price, duration and message.
5. User dashboard — personal bids and statuses.
6. Login — email/password entry.
7. Registration — account details and client/freelancer role.
8. Create job — title, category, description, budget and deadline.
9. Freelancer profile — skills, experience and rating.

## Design system

- Main colors: navy (#152342), blue (#536BEE), teal (#19B69B), white (#FFFFFF).
- Background: light gray-blue (#F5F7FC).
- Typeface: Inter, with consistent heading, body, label, and button styles.
- Repeated patterns: navigation bar, input fields, primary/secondary actions, listing cards, category/status badges.

## Primary clickable user flow

Home → Job catalogue → Job detail → Submit bid → User dashboard.

## Secondary flows

Home → Registration → Dashboard.  
Home → Login → Dashboard.  
Home → Create job → Dashboard.

Some navigation is already connected inside the Figma prototype; the team must verify each intended click-through before the Lab 7 demonstration. Figma forms are visual prototypes, not working backend forms.
