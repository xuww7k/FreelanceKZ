## Project description (approx. 190 words)

FreelanceKZ is a proposed web application that helps university students and beginning professionals find freelance work while helping individuals and small companies find affordable digital services. Many students have programming, design, translation, and presentation skills but struggle to find their first real projects. At the same time, small businesses often need help with limited tasks and budgets. FreelanceKZ connects these two groups through a simple and transparent marketplace.

Clients will register, publish tasks with descriptions, categories, estimated budgets, and deadlines, and review proposals from available freelancers. Freelancers will browse a catalogue, search by category and budget, inspect task details, and submit bids with a suggested price, deadline, and personal message. A client will be able to select a suitable proposal and monitor the project status. After successful completion, both sides will be able to exchange reviews and ratings, building trust within the platform.

The application is planned using Java Spring Boot and a PostgreSQL database. Thymeleaf, HTML, CSS, and JavaScript will provide an accessible web interface. Spring Security will protect authenticated features and distinguish between clients, freelancers, and administrators. The project is intended as a realistic example of layered architecture, relational data modeling, secure user workflows, and team-based web development.

## Main objectives

- Help students gain their first professional project experience.
- Let clients post and manage clear, budgeted assignments.
- Make it easy to find tasks, submit bids, and select a freelancer.
- Build transparency and trust through project status and reviews.
- Demonstrate layered Spring Boot architecture and database integration.

## Target users

1. Students and entry-level freelancers.
2. Individuals and small businesses seeking digital services.
3. Administrators managing platform content.

## Problem solved

Beginners often lack professional references and access to paid projects. Clients find it difficult to evaluate and choose inexperienced but talented specialists. The marketplace gives both groups a structured space to collaborate.

## Expected results

A responsive web application with secure account access, job posting, search, bid submission and selection, project dashboards, persistent PostgreSQL data, and review functionality. **Lab 7 delivers this proposal and UX/UI design only; application implementation is future work.**
